# Realistic TNT (Horizon native mod)

Explosions that look, sound and hit like the real thing: a fireball and a mushroom cloud, a visible
shockwave that hurts, throws and flattens what it sweeps over, a real crater, flying debris and a
delayed boom. TNT adds up with no limit.

This folder is the mod's bundle, what `horizon-launcher native-build` builds:

    horizon-launcher native-build realistic_tnt --instance <your instance> --trust-native-code

The full documentation, the shader packs that draw the fireball and the shockwave, and a video are in
the repository this folder comes from (its README).
